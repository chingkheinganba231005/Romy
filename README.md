# Astronomy × Machine Learning — End-to-End Projects with Real Data

End-to-end Machine Learning projects, each written as a book chapter in the style of Chapter 2 ("End-to-End Machine Learning Project") of *Hands-On Machine Learning with Scikit-Learn and TensorFlow*. Each one follows the same eight steps — big picture, get the data, explore, prepare, train, fine-tune, present, launch — and each one rediscovers a real piece of astronomy from real data.

| Chapter | Project | Main data |
|---|---|---|
| [1](01-rediscovering-keplers-laws/) | **Rediscovering Kepler's three laws** | Tycho Brahe's raw Mars observations (1582–1600), NASA/JPL Horizons, NASA fact sheets |
| [2](02-weighing-the-milky-way-black-hole/) | **Weighing the black hole at the center of the Milky Way** | 25 years of VLT/NTT/Keck astrometry and spectroscopy of the S-stars (Gillessen et al. 2017) |
| [3](03-rediscovering-neptune/) | **Rediscovering Neptune from the motion of Uranus** | NASA/JPL Horizons positions of Uranus (1690–1846), Earth, Jupiter and Saturn |
| [4](04-discovering-dark-energy/) | **Discovering dark energy: the accelerating Universe** | Pantheon+ Type Ia supernovae with SH0ES Cepheid calibrators |
| [5](05-hunting-exoplanets/) | **Hunting exoplanets in NASA Kepler data** | Kepler-90 light curves (MAST) and the Kepler KOI catalog (NASA Exoplanet Archive) |

Every chapter folder contains:

* `index.html` — the guide (theory of the astronomy and of the ML, all the code with its real outputs, all the figures),
* a Jupyter notebook that reproduces every number and figure,
* `animations/` — classroom animations that run on the exact equations and fitted parameters of the chapter,
* `datasets/` — cached copies of the data so everything runs offline.

**Start here:** open the homepage [`index.html`](index.html) in a browser (or enable GitHub Pages for the repository); it links to all the chapters, their animations and notebooks.
